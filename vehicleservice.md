1. New API to update vehicle status to Maintainence or discard. If maintainence, it cannot be assigned to any order and if discard, it should be removed from the system. If the vehicle is in maintainence or discard state, it cannot be assigned to any order and should not be returned in the list of available vehicles. If discard, no operation should be done with it and it's status also cannot be reverted from discard, but for maintainence it can be reverted back to idle
