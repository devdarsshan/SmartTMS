Vehicle-service
1. Method to assign a driver to a vehicle, check if the userid is a driver and if the driver is available from the user-service. Check if the vehicle is idle and assign both
2. Method to unassign a driver from a vehicle, check if the userid is a driver and if the driver is assigned to the vehicle. Unassign both
3. Method to get the current driver of a vehicle, check if the vehicle is assigned to a driver and return the driver details
4. Method to get the current vehicle of a driver, check if the driver is assigned to a vehicle and return the vehicle details
5. Method to get the list of all occupied vehicles with their assigned drivers, return a list of vehicles with their assigned driver details
